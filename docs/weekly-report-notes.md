# 주간 리포트 — 개발 시 참고 노트

일요일(한국 휴장 + 미국 휴장) 발송하는 주간 리포트. 일일 브리핑이 "오늘 스냅샷"이라면, 주간은 **한 주 누적 흐름 + LLM 해석**이 핵심. 일일에 넣으면 너무 길어지는 심층 분석을 여기로 모은다.

## 주간에 넣기로 한 것들 (개발 중 결정 누적)

1. **주체별 자금 이동 심층** ⭐ — 외국인/기관/개인의 *일주일 누적* 순매수를 섹터별로. 일일은 "오늘 담은/판 섹터 1개씩"만 보여주지만, 주간은 "외국인이 한 주 내내 HBM·메모리 담고 개인이 받아냄" 같은 **추세**를 LLM이 해석. (일일에 다 넣으면 과부하라 주간으로 뺀 항목)
2. **섹터 회전(rotation)** — 주초 vs 주말 강세 섹터 변화 → "돈이 2차전지에서 빠져 방산으로 이동" 같은 자금 이동.
3. **주간 강세/약세 섹터** — 5일 누적 등락률·상대강도 기준 랭킹.
4. **한 주 시장 요약** — 코스피·코스닥·S&P·나스닥 주간 등락 + 환율.
5. **LLM 해석** — 위 지표 + 뉴스를 종합해 한국어 내러티브 생성. (LLM 클라이언트는 `notify`처럼 추상화, 키 들어오면 연결)
6. **다음 주 관전 포인트** — 주도 테마 지속 여부 등.

## 데이터 소스 (이미 일별로 쌓이는 중)
- `data/stocks/{KR,US}/*.json` — 종목별 일별 지표 history (OHLCV·시그널·점수, 거래일 기준)
- `data/sectors/{date}/{session}.json` — 섹터 일별 집계
- `data/market/{date}/{session}.json` — 시장 요약 + **수급(flow) 포함** ← 주체별 자금이동 재료
- `data/indices/*.json` — 지수 일별 history
→ 최근 5영업일치 모아서 누적/비교하면 됨.

## 구현 메모
- `scripts/weekly.py` + 일요일 cron (`.github/workflows`에 schedule 추가).
- 발송은 기존 `notify.Notifier` 재사용 (텔레그램 4096자 제한 주의 — 길면 분할 발송 필요).
- 시그널 임계값 튜닝(거래대금 2배 등)도 이 누적 데이터로 백테스트 가능 → `docs/backlog.md` 참고.

> 관련: `docs/backlog.md`(주간 수급 심층/회전), `docs/decisions/`(설계 결정).
