# Decisions Log

섹터·종목·지표·시그널 등 "시장을 보는 관점"을 바꿀 때 **왜 바꿨는지**를 한 줄이라도 남긴다.
이 관점 파일(`config/*.yaml`)이 이 프로젝트의 핵심 자산이라, 변경 이력 자체가 가치다.

## 형식
파일명: `YYYY-MM-DD-짧은제목.md` (또는 이 파일에 누적)

```
## 2026-06-12 — HBM 섹터에 한미반도체 leader 지정
- 변경: stocks.kr.yaml, 042700 leader=true
- 이유: HBM 패키징 장비 대장주, 거래대금 상위
- 근거: (출처/날짜)
```
